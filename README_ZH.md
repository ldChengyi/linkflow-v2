# LinkFlow v2 — 事件驱动的物联网云平台

> 基于事件驱动架构构建的物联网云平台，使用多语言协作 + 企业级中间件。

简体中文 | [English](./README.md)

## 项目背景

LinkFlow v1 采用 Go 单体的流程驱动架构，在功能扩展过程中暴露出严重的耦合问题：模块间直接调用、服务共享数据库表、协议层与业务层混合。本项目在 v2 中通过引入消息总线和领域划分，重构为事件驱动的微服务架构。

## 核心设计

- **事件驱动架构（EDA）**：服务间通过 Kafka 事件总线异步通信，无直接依赖。
- **多语言协作**：各语言用在最擅长的位置 —— Go 写业务、Python 做 AI、Rust 处理性能敏感模块。
- **领域驱动设计（DDD）**：按限界上下文划分服务，独立数据库。
- **可观测性优先**：跨语言、跨服务的分布式链路追踪。

## 技术栈

### 基础设施
- **MQTT Broker**：EMQX 5.x
- **消息总线**：Redpanda（Kafka 协议兼容）
- **关系数据库**：PostgreSQL 16
- **时序数据库**：TimescaleDB 2.x
- **缓存**：Redis 7.x

### 应用服务
- **业务服务**：Go + Kratos
- **AI 服务**：Python + FastAPI
- **接入层**：Rust + Tokio
- **前端**：React + TypeScript + Ant Design Pro

## 分支策略

- `dev` —— 开发分支。所有功能开发在这里进行，达到里程碑后通过 Pull Request 合并到 `main`。
